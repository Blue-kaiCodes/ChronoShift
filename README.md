## 📖 Overview
**ChronoShift** is a premium, SaaS-grade time-synchronization dashboard built for distributed remote teams. It calculates the **"Golden Hour"**—the exact UTC time where the highest percentage of your team members are within their standard working hours (09:00 - 17:00).

## ✨ Features
- **Smart Overlap Engine:** Parses 40+ global timezones and calculates exact availability scores.
- **World-Class UI/UX:** Inspired by Linear, Vercel, and Apple. Features Glassmorphism, ambient lighting, and dark/light mode.
- **Data Visualization:** Beautiful 24-hour Recharts area charts with custom tooltips.
- **Micro-Interactions:** Framer Motion animations on sidebar, cards, and lists.

## 🛠️ Tech Stack
- **React 18** (UI Architecture)
- **Vite 5** (Build Tool)
- **TailwindCSS 3** (Styling)
- **Framer Motion** (Animations)
- **Recharts** (Charts)

## 🚀 Getting Started
1. Clone the repo: `git clone https://github.com/Blue-kaiCodes/ChronoShift-SaaS.git`
2. Install dependencies: `npm install`
3. Start the server: `npm run dev`
